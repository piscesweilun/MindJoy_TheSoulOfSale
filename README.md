# MindJoy | The Soul of Sale

這是一個精美的藝術展覽網頁，採用 React + Vite + Tailwind CSS 開發。

## 啟動說明

請按照以下步驟在本地環境運行專案：

### 1. 安裝相依套件
在專案根目錄下執行：
```bash
npm install
```

### 2. 啟動開發伺服器
執行以下指令來啟動 Vite 開發伺服器：
```bash
npm run dev
```

### 3. 查看網頁
啟動成功後，請在瀏覽器開啟以下網址：
[http://localhost:3000/MindJoy_TheSoulOfSale/](http://localhost:3000/MindJoy_TheSoulOfSale/)

> [!NOTE]
> 由於專案配置了 `base: '/MindJoy_TheSoulOfSale/'`，請確保網址包含該子路徑才能正確載入資源。

## 專案功能
- **藝術畫廊**：展示多項藝術作品與描述。
- **詳情檢視**：點擊作品可查看詳細資訊。
- **影片播放**：支援在懸浮視窗中播放作品相關影片。
- **精美設計**：採用 Cream 奶油色系調色盤，具備優雅的微動畫效果。
